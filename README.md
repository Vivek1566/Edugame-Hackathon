# Edugame Hackathon

An educational gaming website created during the 2025 hackathon. Edugame is designed to make learning more engaging through interactive web-based experiences.

## About the Project

This project explores how games can support education by combining learning content with an interactive website experience. It was built as part of a hackathon focused on creating an educational game platform.

## Tech Stack

- HTML

## Getting Started

### Prerequisites

A modern web browser is all you need to run the project locally.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Vivek1566/Edugame-Hackathon.git
   ```

2. Open the project directory:

   ```bash
   cd Edugame-Hackathon
   ```

3. Open the main HTML file in your browser, or use a local development server.
